## 4. 手动注册操作步骤

本轮实际注册要求：

- 谷雨：注册时勾选注册协议。
- 安吉尔会员：注册时勾选注册协议，并绑定手机号。
- 白马智选：除基础信息外，还需要填写额外表单。

步骤：

1. 在平台“账号”页确认当前使用的微信账号。
2. 在 PC 微信或手机微信打开对应小程序，使用同一个微信账号登录。
3. 完成会员注册/登录，按提示授权手机号；需要实名的应用按小程序要求补充资料。
4. 回到平台，进入应用详情，确认“注册方式”和“注册说明”已标记为“需手动注册”。
5. 手动运行一次签到脚本；如果仍提示未注册，检查是否登录了正确的微信账号。
6. 成功后可在应用信息里把注册方式改为“无需注册”，或保留“需手动注册”作为提示。

## 5. 平台里的记录方式

`Site` 新增：

- `registrationMode`：`unknown` / `none` / `auto` / `one_click` / `manual`
- `registrationNote`：注册说明

应用列表卡片和应用详情会显示注册标签；应用详情的“应用信息”里可以修改。`data/apps/<key>/app.json` 也支持这两个字段，重新导入时会同步。

一键注册时，如果脚本在 `ctx.manualRequired` 的 `details.formSchema` 中声明了字段，页面会弹出表单；提交后的值会作为下一次 Run 的 `ctx.input`。支持 `text / tel / number / textarea / select / checkbox`，必填项会在前端校验。

已支持脚本化注册的应用：

- 自动注册：`gujiajiaju`、`qqhyjlb`、`nice`、`tslj`；手机号授权登录：`haitian`。
- 一键注册：`aiguo`、`choubao`。注册逻辑独立在 `register.js`，可在应用详情的「应用脚本」里直接运行测试；签到脚本发现未注册时返回 `manual_required`，运行详情的「一键注册」会优先提交该应用的注册脚本。
- 需要额外字段的应用，可按 `formSchema` 方式接入：第一次运行返回 `manual_required` 和字段定义，用户提交后第二次 Run 通过 `ctx.input` 读取。

## 6. 为什么没有全部做自动注册

- 部分小程序注册接口需要真实微信客户端的手机号授权数据，YYB 授权数据会被服务端按水印/版本拒绝（如 `fafa`）。
- 部分注册接口在现有包中没有定位到，或需要额外字段（验证码、地区、门店、设备信息）。
- 部分应用登录成功但服务端仍判定未注册，必须先在小程序创建会员记录。
- 协议勾选本身不是问题；真正决定能否一键注册的是**注册接口是否已知、是否需要用户唯一信息、是否接受 YYB 手机号授权**。只有协议且接口已知的应用，可以把注册逻辑拆成独立的 `register.js`，由「一键注册」按钮或手动运行脚本触发。
- 平台不做“伪造注册成功”。脚本只在服务端真正返回成功时标记成功；需要人工处理的应用保持“需手动注册”。
