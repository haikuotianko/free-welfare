# 06 界面设计

## 1. 原则

1. **PC 优先**：桌面侧边栏 + 多列/表格 + 批量操作；手机响应式卡片/底部导航，保证日常可用。
2. **一屏看清今天**：签到进度、失败、积分、待领活动、下一次任务。
3. **状态先于操作**：先告诉用户“现在怎么样”，再给“要做什么”。
4. **渐进披露**：列表只给关键信息；详情展开配置、日志、原始数据。
5. **不假装精确**：有效期/库存未知就标“未知/估算”。
6. **能力驱动**：脚本声明能力，界面只显示支持的功能；先配置应用信息，再配置该应用下的多个脚本。

## 2. 技术

- Vue 3 + TypeScript + Vite
- TailwindCSS + `reka-ui` / `shadcn-vue` 组件
- Pinia（全局状态）+ TanStack Query（服务端数据）
- Vue Router
- `vite-plugin-pwa`（PWA）
- 图标：Lucide
- 图表：ECharts（后续，按需）
- 表单：`vee-validate` + Zod

## 3. 信息架构

### 桌面（主）

```text
侧边栏
├── 总览
├── 账号
├── 应用（站点）
├── 积分
├── 商品
├── 活动
├── 脚本 / 订阅
├── 运行
├── 通知
└── 设置
```

首期菜单可精简为：总览、账号、应用、积分、脚本、运行、设置。商品/活动作为应用详情 Tab，**只有脚本声明了该能力才显示**。

### 手机（次）

```text
底部导航
├── 首页
├── 账号
├── 积分
├── 脚本
└── 我的
```

站点/运行从首页、应用卡片、脚本详情进入；不单独占 Tab。

## 4. 首次启动向导

新部署第一次打开：

1. **创建管理员**：用户名、密码、可选 TOTP。
2. **连接 YYB**：地址、integration token、protocol token；测试连接。
3. **同步账号**：提示去 YYB 控制台扫码；同步后显示账号。
4. **创建/选择应用**：从内置模板或订阅源创建；填应用信息（名称、AppID、图标、积分别名）。
5. **安装脚本**：从官方源安装“每日签到”；应用下可以有多个脚本。
6. **配置脚本**：选择微信账号 + 应用，填脚本配置。
7. **试运行**：手动跑 `login`/`sign_in`，显示结果。
8. **创建任务**：每日签到 cron。
9. **配置通知**：Server酱 token，测试发送。

向导可跳过，之后在设置里补。

## 5. 页面规格

### 5.1 首页

模块：

1. **今日概览**
   - 已签到 `1/1`，失败 `0`，今日积分 `+10`，总积分 `xxx`。
   - 即将过期积分（有数据时）。
2. **待处理**
   - 账号失效：去 YYB 重扫。
   - 需要手机号/注册：去绑定。
   - 验证码待人工：打开运行详情。
   - 脚本更新：去订阅页。
3. **下一次任务**
   - 最近 3 个任务：时间、站点、能力、状态。
4. **快捷操作**
   - 全部签到、同步全部、手动跑脚本。

移动端卡片纵向堆叠；桌面 2 列网格。

### 5.2 账号页

卡片：

- 头像、昵称/备注、YYB 状态徽标、渠道。
- 绑定站点数、最近同步。
- 操作：同步、查看绑定、重扫（跳 YYB）、停用。

详情：

- 基本信息（YYB ref、脱敏 OpenID、渠道、状态）。
- 绑定站点：站点、业务账号、状态、最近登录、余额。
- 最近运行。
- 危险操作：停用/删除本地记录（不删 YYB）。

空状态：引导“先去 YYB 扫码添加账号”。

### 5.3 应用（站点）页

列表/网格：

- 图标、名称、AppID、能力徽标（来自已安装功能脚本）。
- 绑定账号数、最近运行、成功率、脚本版本。

详情 Tab：

1. **应用信息**：名称、AppID、图标、分类、描述、状态。
2. **账号**：site_accounts、状态、余额、最近登录。
3. **功能脚本**：登录/签到/积分/商品/活动/注册，各自启用/停用/版本/调度；公共模块版本与被依赖关系。
4. **积分**（脚本声明 points 时显示）：余额、批次、过期、规则。
5. **商品**（脚本声明 products 时显示）：商品卡片、库存、积分、限购、状态。
6. **活动**（脚本声明 activities 时显示）：任务/活动、进度、领取。
7. **任务**：签到/同步/抢购配置。
8. **运行**：该应用运行记录。

> 原则：**脚本有什么功能就显示什么功能**；没有声明的 Tab 不显示，声明了但接口未补齐的显示“待适配/未启用”。

### 5.4 积分页

- 顶部总览：总积分、即将过期、按站点分布。
- 筛选：站点、账号、过期时间。
- 列表：站点/账号、余额、最近同步。
- 批次时间轴：金额、来源、过期时间、剩余。
- 规则摘要：签到/任务/活动、过期规则。
- 操作：同步、设置提醒阈值、跳转兑换。

视觉：

- ≤7 天橙色，≤1 天红色。
- 估算数据用虚线/“估算”标签。
- 空状态解释“该站点未提供批次数据，只能显示余额”。

### 5.5 商品页

卡片：

- 图片、名称、积分价、库存、限购、状态、结束时间。
- 标签：可兑换/积分不足/售罄/未开始/需支付。
- 操作：兑换（后续）、查看详情。

排序：推荐、积分低到高、最近补货、即将结束。

### 5.6 活动页

- 列表：活动名、类型、奖励、进度条、状态、结束时间。
- 操作：领取（后续）、去完成、忽略。
- 筛选：可领取/进行中/已完成/已结束。

### 5.7 脚本 / 订阅页

**已安装（按应用分组）**：

- 应用信息：名称、AppID、图标、分类。
- 功能脚本：登录、签到、积分、商品、活动、注册；每个单独启用/停用、版本、调度、最近运行、成功率。
- 公共模块：auth/crypto 版本、被哪些脚本使用。
- 操作：更新、回滚、停用、删除。

**订阅源**：

- 源名称、仓库、分支、最近同步、脚本数量、审核状态。
- 可用脚本：名称、版本、AppID、能力（单个）、changelog、安装按钮。
- 更新提示：新版本、变更摘要、权限/依赖变化；公共模块更新提示关联脚本。

**脚本详情**：

1. 概览：README、manifest、能力、允许域名、版本历史。
2. 配置：JSON Schema 自动表单；secret 只显示“已配置”。
3. 绑定：站点 + 账号 + 配置 + 启用。
4. 任务：能力、cron/一次性、超时、重试、并发。
5. 运行：历史、状态、耗时、错误码。
6. 日志：实时 tail、级别筛选、下载。
7. 版本：版本列表、changelog、hash、回滚。

安装流程：

1. 选择订阅源/脚本。
2. 查看权限（允许域名、能力）。
3. 校验 hash。
4. 选择站点（AppID 必须匹配）。
5. 绑定账号、配置。
6. dry-run。
7. 启用任务。

### 5.8 运行页

- 筛选：状态、站点、账号、脚本、时间。
- 列表：状态、能力、站点/账号、开始时间、耗时、错误码。
- 详情：
  - 概要：结果、积分前后、错误。
  - 时间线：开始/取码/登录/请求/完成。
  - 日志：实时 tail、复制/下载。
  - 附件：截图/HAR。
  - 操作：重跑、停止、标记已处理。

### 5.9 设置页

- **YYB**：地址、token（只显示已配置）、健康检查、同步频率。
- **通知**：Server酱 token、测试发送、事件开关。
- **安全**：修改密码、TOTP、会话管理。
- **数据**：日志保留、备份、导出。
- **脚本源**：官方源、自定义源；自定义源强警告，custom 脚本只能用 ctx API。
- **系统**：版本、数据库、磁盘、Worker 状态。

## 6. 关键流程

### 6.1 添加账号

```text
账号页 -> 添加账号 -> 打开 YYB 扫码页（新窗口）
       -> 扫码完成 -> 平台同步 -> 显示账号卡片
```

平台不做扫码协议；直接跳转用户自己的 YYB `/scan` 或 `/account-link`。

### 6.2 安装脚本

```text
脚本页 -> 订阅源 -> 选择“每日签到” -> 查看权限/hash
       -> 安装 -> 绑定账号 -> 手动运行 login/sign_in
       -> 成功 -> 创建每日任务
```

### 6.3 更新脚本

```text
订阅页提示新版本 -> 查看 changelog/权限变化
                -> 更新 -> 校验 hash -> 切换 current_version
                -> 旧版本保留，可回滚
```

### 6.4 失败处理

```text
首页待处理/运行详情
  -> auth_expired/yyb_rescan：跳 YYB 重扫
  -> phone_required：去绑定手机号
  -> captcha_required：人工完成后重跑
  -> script_error：看日志/提 issue/回滚
```

## 7. 组件与状态

### 7.1 通用组件

- `StatusChip`：alive/expired/running/success/failed/warning。
- `PointsBadge`：余额 + 过期颜色。
- `SiteIcon`：站点图标 + 能力角标。
- `TaskCard`：站点、能力、下次运行、状态。
- `ProductCard`：图片、积分、库存、限购。
- `ActivityCard`：进度条、奖励。
- `RunLogViewer`：虚拟滚动、级别过滤、自动 tail。
- `ConfigForm`：JSON Schema -> 表单。
- `EmptyState` / `ErrorState` / `Skeleton`。
- `ConfirmSheet`：移动端底部确认。

### 7.2 列表状态

每个列表都要有：

- loading：骨架屏。
- empty：说明 + 下一步。
- error：原因 + 重试。
- partial：部分数据不可用。

## 8. 桌面适配

- `>= 1024px`：左侧固定侧边栏 + 顶部栏；内容最大宽度 1200-1440px。
- 运行/商品/积分批次可切换表格。
- 详情双栏：主内容 + 右侧元信息。
- 快捷键（可选）：`g h` 首页、`g a` 账号、`g s` 脚本、`/` 搜索。

## 9. PWA

- `manifest.webmanifest`：名称、图标、主题色、`display: standalone`。
- Service Worker：缓存应用壳/静态资源；API 不缓存敏感数据。
- 添加到主屏幕引导。
- 离线：只读最近数据，标记“离线数据”。
- 推送：首期 Server酱，不依赖 Web Push。

## 10. 视觉风格

- 干净、轻量、信息密度适中，避免厚重后台感。
- 主题色：可自定义（默认蓝/青）；状态色：绿/橙/红。
- 卡片圆角 12-16px，阴影轻，分割线少。
- 系统字体；数字用等宽/表格数字。
- 浅色 + 深色：CSS 变量，跟随系统，也可手动切换。
- 图标：Lucide；站点图标远程 + fallback。

## 11. 可访问性与性能

- 触控目标 ≥44px；对比度 ≥4.5:1。
- 表单 label 明确；错误信息靠近字段。
- 虚拟滚动（运行/日志/商品）。
- 图片懒加载 + 占位。
- 路由懒加载；首屏 JS 控制。
- 移动网络避免大图/大日志一次性加载。

## 12. 首期页面优先级

| 优先级 | 页面 | 原因 |
| --- | --- | --- |
| P0 | 首次向导、登录 | 能开始用 |
| P0 | 首页、账号、脚本、运行详情 | 日常核心 |
| P0 | 应用详情（应用信息/功能脚本/积分） | 资产视图 |
| P1 | 商品/活动 Tab | 应用接口补齐后 |
| P1 | 设置（YYB/通知） | 首次配置 |
| P2 | 订阅源管理、审计 | 完善体验 |
