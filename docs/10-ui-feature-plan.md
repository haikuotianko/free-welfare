# 10 界面与功能规划

本文把 [06 界面设计](06-ui-ux.md) 收敛成首期可落地的页面/功能清单。目标：**PC 上完整管理/批量/排错，手机上也能快速看今日状态和处理失败。**

## 1. 产品感觉

- 个人工具，不是企业后台；信息密度适中，不堆菜单。
- PC 是主界面：侧边栏、多列卡片、表格、批量操作。
- 手机是随身看板：今日状态、积分、失败处理。
- 每天打开 30 秒：今天签到了吗？积分多少？有没有失败？
- 失败时知道下一步：重扫、补手机号、看日志、更新脚本。
- 不假装精确：没有总余额/有效期就标“未知/估算”。
- 视觉干净、轻、可信；浅色 + 深色 + 自定义主题色。

## 2. 导航

### 桌面侧边栏（主）

```text
总览
账号
应用（站点）
积分
商品
活动
脚本 / 订阅
运行
通知
设置
```

- **总览**：今日任务、资产摘要、待处理、下次任务。
- **账号**：微信账号、YYB 状态、重扫、绑定应用。
- **应用**：应用信息（名称/AppID/图标）+ 该应用下的多个脚本配置。
- **积分**：积分、规则、即将过期。
- **商品/活动**：只有脚本声明了对应能力才显示。
- **脚本/订阅**：已安装脚本、订阅源、更新/回滚、任务、日志。
- **运行**：全部运行记录、筛选、排错。

### 手机底部（次）

```text
首页    账号    积分    脚本    我的
Today  Accounts Points Scripts Me
```

- 首页：今日任务、待处理、积分、下次任务。
- 账号：微信账号、状态、重扫。
- 积分：积分、规则。
- 脚本：已安装脚本、更新、运行记录。
- 我的：YYB 设置、通知、安全、系统。

> 应用/站点不单独占手机 Tab：从首页卡片、账号详情、脚本详情进入。

## 3. 首页

### 3.1 目标

30 秒内回答：

1. 今天签到了吗？
2. 有没有失败/需要我处理？
3. 积分大概多少？
4. 下一次任务什么时候？

### 3.2 桌面布局

12 栅格：

```text
┌──────────────────────────────────────────────────────────┐
│ 总览   11月13日 周四        [全部签到] [同步全部] [⚙️]   │
├──────────────────────────────────────────────────────────┤
│ 今日 1/1 已完成   +10 积分   总积分 120（估算）  待处理 1 │
├───────────────────────────────┬──────────────────────────┤
│ 今日任务（卡片网格 2-3 列）     │ 待处理                    │
│ ┌──────────┐ ┌──────────┐     │ ⚠ 账号 A 需要重扫         │
│ │ 示例应用  │ │ ...      │     │ ⚠ 脚本更新                │
│ │ ✅ 已签到 │ │          │     ├──────────────────────────┤
│ └──────────┘ └──────────┘     │ 积分摘要                  │
│                               │ 积分 120 / 即将过期 —    │
│ 最近运行                       ├──────────────────────────┤

```

### 3.3 手机线框（单列）

```text
│ 积分 120 · 即将过期 10         │

├─────────────────────────────┤

├─────────────────────────────┤
│ 积分                         │
│ 总积分 120（估算）            │
│ 即将过期：—（暂无数据）        │

│ 下次任务                     │

├─────────────────────────────┤
│ 首页   账号   积分   脚本   我的│
└─────────────────────────────┘
```

### 3.3 模块

1. **顶部状态**：日期、今日完成数、今日获得。
2. **今日任务**：每个 site_account 一张卡；状态（已完成/待执行/失败/需人工）、积分变化、时间。
3. **待处理**：账号失效、手机号、验证码、脚本更新、连续失败。
4. **积分摘要**：总积分、即将过期；没有数据时明确“暂无/估算”。
5. **下次任务**：最近 3 个定时任务。
6. **快捷操作**：全部签到、同步全部、手动跑脚本。
7. **最近运行**：最近 5 条，点进日志。

### 3.4 空状态

- 没有账号：引导“连接 YYB → 扫码添加账号”。
- 没有脚本：引导“从订阅源安装每日签到”。
- 没有任务：引导“创建每日签到任务”。

## 4. 账号页

### 4.1 列表

卡片：

```text
┌─────────────────────────────┐
│ [头像] 微信昵称 / 备注        │
│ 🟢 可用 · YYB 渠道           │
│ 绑定 1 个站点 · 10:30 同步    │
│ [同步] [查看] [重扫]          │
└─────────────────────────────┘
```

状态：

- `alive` 绿色“可用”
- `session_only` 黄色“部分可用”
- `unknown` 灰色“未知”
- `expired` 红色“需重扫”
- `disabled` 灰色“已停用”

### 4.2 详情

- 基本信息：YYB ref、脱敏 OpenID、渠道、状态、最近同步。
- **绑定站点**：示例应用、业务账号状态、积分、最近登录、脚本版本。
- 最近运行：状态、时间、错误码。
- 操作：同步、刷新状态、打开 YYB 重扫、停用、删除本地记录。

### 4.3 添加账号

```text
账号页 -> 添加账号
  -> 打开 YYB 控制台扫码页（新窗口）
  -> 手机微信扫码
  -> 回到平台点“同步”
  -> 显示新账号
```

不做自己的扫码协议；直接复用 YYB。

### 4.4 应用详情（应用信息 + 多脚本）

应用（站点）是主实体：

```text
应用信息
  名称 / AppID / 图标 / 分类 / 描述 / 状态
账号
  绑定的微信账号 + 业务账号状态 + 会话状态
功能脚本
  ✅ 登录    v0.1.0
  ✅ 签到    v0.1.0  每天 08:43
  ✅ 积分    v0.1.0  每天 09:10
  ⏸ 商品    v0.1.0  待接口
  ⏸ 活动    v0.1.0  待接口
  ⏸ 注册    —       待确认
公共模块
  示例公共模块 v0.1.0（auth/session）
依赖
  crypto-js 4.2.0（如有）
网络
  模式：● 白名单   ○ 不限制（警告）
  根 URL：api.example.com; img.example.com（自动补 https:// 并生成白名单）
```

- **先配置应用信息，再配置该应用下的多个功能脚本。**
- 能力驱动：只有脚本声明了 `products/activities`，才显示商品/活动入口。
- 每个功能脚本可单独启用/停用、调度、更新/回滚、看日志。
- 公共模块不可直接运行，只显示版本和被哪些脚本使用。
- 网络白名单在应用级配置；脚本 manifest 只能缩小，不能扩大。
- `unrestricted` 需二次确认，红色警告；默认不开启。

## 5. 积分页

### 5.1 首期（首个应用）

- 顶部：积分余额、即将过期、连续签到天数。
- 有效期：应用返回的截止日期；显示“有效期截止至 {date}”。
- 规则：消费/签到/活动获得的规则由应用说明；兑换规则以应用内说明为准。
- 预警：有即将过期积分时显示；12 月加强提醒。

### 5.2 后续（多站点）

- 总积分、按站点分布、即将过期时间轴。
- 批次列表：金额、来源、过期时间、剩余。
- 筛选：站点、账号、过期时间。
- 标记“估算”的数据。

### 5.3 空状态

“该站点还没有积分数据。先运行一次签到/同步。”

## 6. 商品/活动页

### 6.1 首期

- **脚本有什么功能就显示什么功能**：只有脚本 manifest 声明了 `products/activities`，才显示对应入口。
- 脚本声明了但接口还没补齐：显示“待适配/未启用”，不展示空列表。
- 接口补齐后：
  - 商品卡片：图片、名称、积分价、库存、限购、状态、结束时间。
  - 活动卡片：名称、类型、奖励、进度、状态。
  - 只读；兑换/领取 Phase 3。

### 6.2 商品状态

- 可兑换（积分够、有库存）
- 积分不足
- 售罄
- 未开始
- 已结束
- 需支付（Phase 3，人工）

## 7. 脚本 / 订阅页

### 7.1 已安装（按应用分组）

```text
应用：示例应用  wxfe13a2a5df88b058
├── ✅ 登录       v0.1.0   手动/测试
├── ✅ 签到       v0.1.0   每天 08:43   成功率 100%
├── ✅ 积分       v0.1.0   每天 09:10
├── ⏸ 商品       v0.1.0   待接口
├── ⏸ 活动       v0.1.0   待接口
└── ⏸ 注册       —        待确认
公共模块：示例公共模块 v0.1.0（被 3 个脚本使用）
```

- **一个功能一个脚本**：登录、签到、积分、商品、活动、注册分别启用/停用。
- 公共模块不直接运行，只显示版本/被依赖关系。
- 每个功能脚本可单独更新/回滚/调度/看日志。

状态：正常/有更新/运行失败/已停用/依赖安装失败。

### 7.2 订阅源

- 官方源：仓库、分支、最近同步、脚本数。
- 自定义源：添加 GitHub URL；强警告；custom 只能用 ctx API。
- 可用脚本列表：名称、版本、能力、AppID、审核状态、changelog、安装。
- 更新：显示功能脚本/公共模块的新版本；公共模块更新后提示关联脚本更新；manual/auto 按脚本配置。

### 7.3 脚本详情

Tab：

1. **概览**：README、manifest、能力、允许域名、依赖、版本、审核状态。
2. **配置**：JSON Schema 表单；secret 只显示“已配置”。
3. **绑定**：站点 + 账号 + 配置 + 启用。
4. **任务**：签到 cron、超时、重试、更新策略；运行/停止。
5. **运行**：历史、状态、耗时、错误码。
6. **日志**：实时 tail、级别筛选、下载。
7. **版本**：版本列表、hash、changelog、回滚。

### 7.4 安装向导

```text
选择订阅源 -> 选择脚本 -> 查看权限/依赖
  -> 安装（显示依赖安装日志）
  -> 绑定账号
  -> dry-run（登录可执行，签到跳过）
  -> 创建每日任务
  -> 完成
```

## 8. 运行页

### 8.1 列表

- 筛选：状态、站点、账号、脚本、日期。
- 行：状态、能力、站点/账号、开始时间、耗时、错误码。
- 手机：卡片；桌面：表格。

### 8.2 详情

- 概要：结果、积分前后、错误、脚本版本。
- 时间线：开始 → 取码 → 登录 → 签到 → 完成。
- 日志：实时 tail、复制、下载。
- 附件：截图/HAR（后续）。
- 操作：重跑、停止、标记已处理。

### 8.3 错误提示

- `yyb_rescan`：账号失效，去 YYB 重扫。
- `auth_expired`：会话失效，自动重登失败，查看日志。
- `phone_required`：需要手机号授权。
- `captcha_required`：需要人工验证。
- `script_error`：脚本 bug，提 issue/回滚。
- `network_error`：网络问题，自动重试。

## 9. 我的/设置

- **YYB**：地址、integration token、protocol token、测试连接、同步频率、打开 YYB 控制台。
- **通知**：Server酱 token、测试发送、事件开关；可配置**多个汇总时间**（如 09:00、21:00），没有信息就不发；失败/账号失效/脚本更新默认开。
- **安全**：修改密码、TOTP、会话管理。
- **脚本源**：官方源、自定义源；custom 警告。
- **数据**：备份、导出、日志保留。
- **系统**：版本、数据库、磁盘、Worker 状态。
- **关于**：MIT、GitHub、文档。

## 10. 首次向导

```text
1. 创建管理员
2. 连接 YYB（地址 + token + 测试）
3. 去 YYB 扫码 + 同步账号
4. 创建应用：示例应用（名称/AppID/图标/分类）
5. 安装功能脚本：登录、签到、积分（一功能一脚本）
6. 绑定账号 + 配置 + dry-run
7. 创建每日签到/积分任务
8. 配置 Server酱 + 测试
```

可跳过；首页显示未完成步骤。

## 11. 移动端交互

- 底部导航 + 安全区。
- 卡片左/上状态色；状态 chip。
- 主操作一个按钮，次要操作放“更多”。
- 底部弹层确认（兑换/删除/更新）。
- 下拉刷新；列表无限滚动。
- 骨架屏/空状态/错误重试。
- 日志虚拟滚动 + 自动 tail 开关。
- Toast 反馈；失败给可读原因。
- PWA 添加到主屏幕。

## 12. 桌面端

- 左侧固定侧边栏 + 顶部栏。
- 表格：运行、商品、积分批次。
- 详情双栏。
- 批量操作：同步全部、全部签到、批量更新脚本。
- 搜索：账号/站点/脚本/运行 ID。

## 13. 视觉

- 主题色：可自定义（默认蓝 `#2563EB`，可选青 `#0F766E`）。
- 浅色 + 深色都支持；跟随系统，也可手动切换。
- 状态：绿 `#16A34A`、橙 `#D97706`、红 `#DC2626`、灰。
- 背景：浅色浅灰白；深色炭黑。
- 卡片：16px 圆角、细边框、轻阴影。
- 字体：系统字体；数字等宽。
- 图标：Lucide；站点图标圆角方块 + fallback 字母。
- 图表：首期不用；后续 ECharts 按需。

## 15. 已确定与剩余

### 已确定

- **PC 优先，手机端友好**：桌面侧边栏 + 多列/表格；手机底部导航 + 单列卡片。
- **首页全部卡片**：今日任务、待处理、积分摘要、下次任务、最近运行。
- **浅色 + 深色 + 自定义主题色**。
- **Server酱**：可配置多个汇总时间；没有信息就不发；失败/账号失效/脚本更新默认开。
- **能力驱动**：脚本声明什么能力就显示什么功能；应用信息 → 多个功能脚本。
- **一功能一脚本 + 公共模块**：登录/签到/积分/商品/活动/注册各自独立，公共逻辑放 common。

### 剩余（不阻塞）

- 默认汇总时间用哪几个？建议 `09:00`、`21:00`，用户可改。
- 默认主题色用蓝还是青？建议蓝 `#2563EB`，可改。
- 应用卡片上是否直接显示公共模块版本？建议放在应用详情，不占首页。
- 手机端首页是否需要“全部签到”大按钮？建议有，但放快捷操作区。
